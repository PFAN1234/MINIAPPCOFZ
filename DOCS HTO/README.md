# Documentos HTO — entradas locais

Os arquivos originais de engenharia são fornecidos separadamente e ignorados pelo Git. O modelo ARQ tem aproximadamente 208 MB. Os scripts esperam esta organização, relativa à raiz do repositório:

```text
DOCS HTO/
├── IFC/
│   ├── CE01-14PE01-ARQ-R05.ifc
│   ├── CE01-14PE01-ANT-R01.ifc
│   └── CE01-14PE01-TLD-R00.ifc
└── PDF/
    ├── CE01-14PE01-ARQ-DE017-R05.pdf
    └── CE01-14PE01-ARQ-DE018-R05.pdf
```

Preserve os originais. Os derivados e os scripts ficam em `artifacts/validation/`. Os mockups e a montagem do GIF podem ser usados sem esses arquivos originais.

As demais siglas exibidas no mockup (ELT, HID, ESG, DRE, PCI e VES) vieram de uma captura da lista de projetos; sua inclusão visual não indica que os respectivos modelos foram importados ou validados.
